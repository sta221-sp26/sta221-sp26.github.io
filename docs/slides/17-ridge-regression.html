When is ridge useful

Most useful for models in which the SE of OLS are large and unstable but you want to keep all the predictors

  • That lambda I term helps stablize the variance when x^tX is nearly singular.

  • So this is the case when there is high multicollinearity

  • when P is close to n

  • Makes it possible to estimate coefficients when p > n (is this true)?

LImitations

  • Ridge will not ever set the coefficients to exactly equal to 0 (limitation if you want to reduce the number of coefficients in th emodel)

    • Similar method called LASSO that addresses this
